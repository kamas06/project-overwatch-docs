# Project Overwatch — User Guide

Welcome to Project Overwatch, the membership management system for the shooting club. This guide explains how to use the app's day-to-day workflows through the UI.

Whether you're onboarding new members, tracking membership status changes, or sending communications to members, start with the guide below that matches what you're doing right now.

## Guides

### [Member Lifecycle & Workflows](member-workflow.md)

Learn how to manage member records from joining the waiting list through probation, full membership, sabbatical, suspension, and beyond. Use this when:
- Adding a new prospective member to the waiting list
- Accepting a waiting-list member into probation
- Promoting a probationer to full membership
- Recording membership changes (suspension, sabbatical, or departure)

### [Emails, Templates, and Campaigns](emails.md)

Learn how to send member communications — from one-to-one emails to templated workflows to bulk campaigns. Use this when:
- Sending a custom email to a single member
- Using a template for consistency (e.g., welcome letters, policy notifications)
- Launching a bulk email campaign to multiple members
- Managing the library of reusable email templates and merge variables
